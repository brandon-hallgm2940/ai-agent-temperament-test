## Overview

agent temperament test is a web application for assessing the temperament of AI agents. Its questionnaire follows a self-report approach, allows responses to be supported with evidence, and organizes the result into five separate scales for straightforward interpretation.

Results are also rendered as a radar chart, providing a quick visual view of how the scales relate to one another. The project can be used in agent evaluation workflows, research experiments, demonstrations, and other structured temperament review scenarios.
